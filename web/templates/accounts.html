Аккаунты

Аккаунты с отдельными адресами работают параллельно и разбирают общую очередь предметов. Один лот получает одно уведомление.

У каждого аккаунта своя сессия, пауза и статистика. Для одинакового исходящего IP действует общий темп и общая остановка после 429. Независимость лимитов разных аккаунтов и IP проверяется по фактическим результатам.

Новый аккаунт добавляется выключенным: «Войти через Steam» → автоматическое сохранение и проверка сессии → «Включить». Можно также вставить curl вручную. Основной аккаунт использует сессию из прежних настроек.

Массовое добавление аккаунтов и прокси

Форматы: login:password или login;password;proxy. Если пароль содержит «;», используйте формат с «;» и заключите пароль в двойные кавычки. Двойную кавычку внутри такого пароля удвойте.

Поддерживаются host:port, host:port:login:password и URL HTTP/HTTPS или SOCKS5 без авторизации. Можно указать прокси третьим полем строки аккаунта — тогда оставьте отдельный список пустым. «-» означает адрес сервера. При пустом списке все аккаунты используют адрес сервера.

Вход выполняется по очереди. Ошибка одного аккаунта не останавливает остальные; при капче можно открыть его окно. Повторный импорт тех же логинов продолжит работу с существующими профилями и пропустит уже проверенные сессии. Общий предел — 200 профилей вместе с основным.

Пароли Steam остаются только в памяти до обработки или отмены. При выходе из панели или перезапуске службы очередь остановится; для продолжения вставьте список заново. Список паролей после отправки не показывается.
